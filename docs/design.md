## 1. 项目背景与术语定义

### 1.1 背景
在现代以大语言模型（LLM）为辅助核心的软件工程中，开发者频繁需要将本地工程中多个相关源代码文件及其物理目录拓扑结构一次性传递给 LLM 上下文。传统手动复制效率低下且容易丢失相对路径与结构元信息。

`KeyboardCommand` 桌面端的 `/folder-copy` 模块旨在提供高性能、精确过滤、支持大目录分页及历史版本追溯的文件浏览与上下文打包体验。

### 1.2 正式术语
- **文件上下文包（File Context Package）**：复制操作的标准化产物，以 Markdown 格式呈现，头部包含根目录绝对路径、生成时间戳、树状拓扑清单，随后以 Markdown 代码块依次输出每个所选文件的相对路径、语言类型及完整源码。
- **三态选择（Tri-State Selection）**：
  - `checked`（全选）：目录中所有符合规则的可用文件均被勾选；
  - `indeterminate`（部分选中）：目录内存在部分符合规则的文件被勾选；
  - `unchecked`（未选）：目录内无任何文件被勾选。
- **已忽略目录（Ignored Directory）**：命中忽略规则（如 `node_modules`、`.git`、`dist` 等）的目录节点，呈现置灰并标注「已忽略」，不可向下展开且无法被勾选。
- **大目录阈值（Large Directory Threshold）**：当某一目录下直接子节点数超过该正整数阈值（默认 50 项）时，首次展开仅加载前 30 项，底部提供「加载更多」分页机制。

当窗口尺寸收缩或嵌入狭窄分屏时，主工作区自动降级为**单面板标签切换**：
- 顶部保留整合式地址栏与独立搜索行；

- 底部「复制文件上下文包」操作栏始终吸底常驻，确保无论切到哪个面板，复制核心 CTA 随时可用。

## 4. 新增功能落地规格说明

### 4.1 系统级设置与页面级规则设置解耦

#### 业务冲突背景
原版本中将应用全局外观、软件版本更新、SQLite 监控与当前目录文件白名单/排除规则放置于同一弹窗，导致系统级配置与业务页面配置职责不清。

#### 解决方案
1. **全局系统设置（`SystemSettingsModal`）**：
   - **入口**：常驻于 Windows 标题栏最右侧，紧邻窗口最小化 `[-]` 按钮。
   - **功能范畴**：
     - **外观主题**：系统跟随（自动检测 OS 明暗）、浅色模式、深色模式；
     - **应用更新**：显示客户端版本号（v1.2.4）、更新通道、检查更新与发布日志；
     - **存储核心**：SQLite 嵌入式存储引擎状态指示（DB 文件路径、读写连接状态）；
     - **系统全局热键**：展示快捷键速查清单。
2. **页面规则设置（`SettingsModal`）**：
   - **入口**：放置于地址输入框右侧的 `[⚙ 规则设置]` 按钮。
   - **功能范畴**：
     - **文件白名单**（按扩展名或全名，如 `.ts`, `.tsx`, `.json`）；
     - **文件排除规则**（Glob 格式，如 `*.test.ts`, `*.min.js`）；
     - **忽略目录清单**（如 `node_modules`, `.git`, `dist`）；
     - **大目录分页阈值**（强校验正整数，输入非法值即刻禁用保存按钮并标红）；
     - **独立恢复机制**：每个纵向分区提供独立的「恢复默认值」，互不影响；
     - **持久化异常演练**：提供 SQLite 保存失败/读取失败时的容错模拟与重试机制。

### 4.2 整合式地址栏与右侧操作按钮区

#### 设计演进
- 移除了原设计中脱离实际桌面体验的伪 Web URL 地址；
- 主操作区第一行采用居左弹性输入框与居右功能按钮组：
  - **左侧输入框（`flex-1`）**：
    - 支持手动文本输入、修改、键盘粘贴；
    - 按 <kbd>Enter</kbd> 触发文件夹校验并加载；按 <kbd>Esc</kbd> 还原未保存的路径编辑；
    - 内置「一键复制当前完整路径」按钮，成功后呈现 2 秒绿色勾选动效；
    - 尾部附带历史下拉箭头，展开最近 10 条使用过的目录记录。点击历史项不仅切换根目录，还会自动恢复该目录在历史记录中最后一次勾选的文件状态。
  - **右侧按钮组（`shrink-0`）**：
    - `[📁 选择文件夹]`：调用系统文件夹选择能力；
    - `[↻ 重新载入]`：对当前路径重新执行物理文件扫描并重置状态；
    - `[⚙ 规则设置]`：呼出页面专有规则配置。

### 4.3 颜色主题跟随系统全链路适配

#### 实现架构
- 引入全局 `ThemeContext`（基于 React Context）；
- 选项包括：
  - `system`（跟随系统）：监听 `window.matchMedia('(prefers-color-scheme: dark)')` 的 `change` 事件；
  - `light`（浅色模式）：强制清除 html 元素的 `dark` 标识；
  - `dark`（深色模式）：强制为 html 元素注入 `dark` class；
- 采用 Tailwind CSS v4 `@custom-variant dark (&:where(.dark, .dark *));` 体系，保证从标题栏、树形菜单、下拉菜单、模态弹窗到滚动条无死角平滑适配。

---

### 4.4 右键菜单单文件独立复制（无副作用）

#### 交互规则
- **适用对象**：仅在文件树中**符合当前规则的有效文件节点**上右键时触发（目录节点与被忽略节点不弹出）；
- **菜单呈现**：精准跟随鼠标光标出现，点击外部或按 <kbd>Esc</kbd> 自动关闭；
- **核心执行逻辑**：
  1. 读取目标单文件的完整内容；
  2. 生成仅含该文件的标准 Markdown 上下文包；
  3. 写入系统剪贴板；
  4. 新增一条历史记录（标记文件数为 1）；
  5. **关键不变量**：**绝不改变当前主界面上已经勾选的任何其他文件或文件夹的选择集合**。

---

### 4.5 fd-find 状态内联嵌入与搜索增强

#### 优化点
1. **状态内联**：当底层 `fd-find` 工具不可用时，不再在工作区弹出突兀的独立警告卡片，而是直接将搜索输入框置灰，右侧内嵌 `[⚠ fd 不可用]` 红色标识，并在 placeholder 提供 `winget install sharkdp.fd` 修复指引；
2. **快捷检索**：支持全局 <kbd>Ctrl+F</kbd> 聚焦；
3. **匹配子串高亮**：下拉匹配列表中的文件名称及相对路径，命中用户输入字符的部分自动用 `<mark>` 标签进行醒目高亮；
4. **键盘连续操作**：在搜索下拉项中，<kbd>Enter</kbd> 选中文件节点后，文件树即刻联动勾选并同步计数，**搜索下拉菜单保持开启**，便于用户一次搜索后连续勾选多个匹配项。

## 5. UI 视觉与交互逻辑深度优化

### 5.1 文件树全键盘漫游与批量工具

#### 键盘映射
| 按键 | 目标节点类型 | 行为说明 |
| :--- | :--- | :--- |
| <kbd>↑</kbd> | 任意节点 | 焦点向上移动到上一个可视节点，触发滚动补偿 |
| <kbd>↓</kbd> | 任意节点 | 焦点向下移动到下一个可视节点，触发滚动补偿 |
| <kbd>Space</kbd> / <kbd>Enter</kbd> | 目录节点 | 展开或折叠该目录（已忽略目录无响应） |
| <kbd>Space</kbd> / <kbd>Enter</kbd> | 文件节点 | 切换选中状态（勾选 / 取消勾选） |
| <kbd>→</kbd> | 目录节点 | 若处于折叠态则展开；若已处于展开态则步入其首个子节点 |
| <kbd>←</kbd> | 任意节点 | 若处于展开态目录则折叠；其余情况下快速跳回至父级目录节点 |

#### 批量快捷栏
文件树卡片顶部常驻精简子工具条：
- `全部展开`：递归打开所有非忽略目录；
- `全部折叠`：一键关闭所有分支；
- `全选符合规则`：一次性将当前根目录下所有穿透规则过滤后的文件加入选择集；
- `清空选择`：快速重置选中集。

---

### 5.2 已选文件清单与 Token 估算

- **数据排版**：采用 `tabular-nums font-mono` 等宽字体，避免数字跳动；
- **智能 Token 估算器**：采用平均字符密度算法（`Math.round(totalBytes / 3.8)`）实时推算所选文件打包后的 Token 占用规模，为用户向大模型提示词粘贴提供容量预期；
- **路径清单导出**：清单头部提供 `[复制路径]` 按钮，一键将勾选文件的相对路径以换行符分隔导出至剪贴板；
- **快速移除**：每个已选条目右侧均有快速移除按钮，点击后立即同步剔除并更新文件树三态复选框。

---

### 5.3 复制操作栏与反馈闭环

- **主按钮文案**：严格固定为 **“复制文件上下文包”**（附带 `Ctrl+Shift+C` 快捷键角标与已选数量徽标）；
- **禁用规则**：已选文件数为 0 或正在执行读取时强禁用；
- **加载状态**：执行复杂打包时显示微型 Loading 旋转动画；
- **多层级异常反馈**：
  - **单文件读取失败（普通复制）**：取消整次复制，弹出 `FailureDialog` 列出失效路径和底层错误代号（如 `EBUSY`, `EACCES`），保留当前已有勾选；
  - **历史记录重读部分失败**：继续打包复制成功的文件，并在右下角浮动提示中说明失效剔除项，用新快照平滑更新历史记录。

### 5.4 13 态交互验证条的可折叠机制

为了保证开发评审人员能够随时验证产品规则，同时不影响日常作为实际工具使用时的视觉清爽度，设计了 `StatePresetBar` 折叠机制：
- **收起状态**：仅占 24px 高度，显示当前模式与快速展开按钮；
- **展开状态**：平铺 13 个关键状态验收按钮及布局规范决议入口：
  1. 正常状态（基准 2/3 : 1/3 分栏）
  2. 搜索结果超过 10 条提示截断
  3. 搜索无结果空状态
  4. fd-find 不可用
  5. 搜索不完整（底层访问受限）
  6. 空选择（复制按钮禁用）
  7. 空目录 / 无符合规则文件空状态
  8. 无历史记录空状态
  9. 大目录分页（75 项 icons 目录首次展示 30 项）
  10. 复制失败对话框（EBUSY / EACCES）
  11. 历史重读部分文件丢失容错处理
  12. 页面规则设置弹窗（4 分区校验）
  13. 右键复制单文件（无副作用）

## 7. 键盘快捷键与操作速查表

| 快捷键 | 作用区域 | 功能说明 |
| :--- | :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>F</kbd> | 全局任意位置 | 快速聚焦搜索栏并选中已输入的文本 |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> | 全局任意位置 | 执行「复制文件上下文包」（需已勾选至少 1 个文件） |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 文件树 | 在所有可视节点间移动高亮聚焦框 |
| <kbd>Space</kbd> | 文件树 | 切换当前聚焦文件的选中状态，或展开/折叠当前聚焦目录 |
| <kbd>→</kbd> | 文件树 | 展开当前目录，或进入其首个子项 |
| <kbd>←</kbd> | 文件树 | 折叠当前目录，或跳回父级目录 |
| <kbd>鼠标右键</kbd> | 可选文件节点 | 弹出「仅复制当前文件」菜单，单文件打包且不改变当前批量勾选 |
| <kbd>↑</kbd> / <kbd>↓</kbd> | 搜索下拉菜单 | 在搜索匹配项间移动高亮项 |
| <kbd>Enter</kbd> | 搜索下拉菜单 | 文件项：切换勾选并保持下拉开启；目录项：仅定位展开 |
| <kbd>Enter</kbd> | 地址输入框 | 提交并载入输入的文件夹绝对路径 |
| <kbd>Esc</kbd> | 地址输入框 | 放弃当前未提交的修改，还原为当前有效路径 |
| <kbd>Esc</kbd> | 所有弹窗/菜单 | 关闭当前打开的弹窗、上下文菜单或下拉列表 |
